项目简介： 独立开发的桌面端即时通讯应用，完整实现登录注册、好友管理、添加好友、单聊 / 群聊、实时音视频通话等核心功能。
在客户端业务方面做了下列核心功能 

封装无边框窗口基类 BasicWindow（自定义标题栏、拖拽、双击最大化）与 QSS 动态换肤模块，QPainter 实现圆形头像裁剪，业务窗口统一继承复用。
MVC 聊天列表：基于QAbstractListModel+ 自定义 ItemDelegate 自绘聊天气泡；QMap 管理多会话消息，支持多类型消息与本地持久化；图片哈希缓存优化，解决 ListView 滚动卡顿，动态计算条目高度实现收发消息左右气泡布局。

使用单例 对象WindowManager 统一管理所有聊天窗口、管理员窗口，防止重复创建相同会话窗口，集中维护窗口生命周期，是 IM 客户端全局窗口调度核心。
P2P 音视频通话：信令媒体分离，TCP 传呼叫信令，UDP 传输 H.264 音视频；Qt 采集摄像头帧，FFmpeg 软编解码，零延迟编码参数；实现 UDP NALU 分片重组，周期下发 SPS/PPS 抗丢包；自定义视频渲染控件；统一封装资源释放逻辑，防止内存泄漏。集成 FFmpeg 实现 P2P 视频通话，H.264 编解码，自定义 UDP 帧协议支持分片重组
离线消息服务端缓存和已读回执发送。用户登录主动向服务端拉取离线消息,并进行消息未读红点标记(ContactItem 重写 paintEvent 自绘红色角标)，当用户点开会话则向服务端发送已读回执，并删除该未读红点标记.

树形好友管理分组，新建分组、 删除分组、 将当前好友移动到该分组。

全局文件与 JSON 序列化操作类 统一管理本地缓存目录（头像 / 群成员 / 聊天图片 / 联系人分组 / 服务器配置），自动创建目录；JSON 实现群成员、聊天记录、联系人分组持久化，提供结构体↔JSON、ChatMsg↔QByteArray/QVariantMap 转换工具；图片缩放 JPEG 压缩落盘；时间戳 + 自增 ID 生成唯一文件名。
客户端服务器配置与连接管理面板 单例配置面板，JSON 持久化服务器 IP / 端口。

实现应用层心跳超时检测：客户端定时向服务端发送心跳包，服务端记录Sock最后活跃时间 Timer定时清理超时僵尸连接
